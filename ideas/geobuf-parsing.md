# Geobuf Parsing Support

## Context
The `sprint-antoine` branch had `src/parsing/geobuf/mod.rs` for parsing geographic buffer data.
This would enable ingestion of geospatial data in an efficient binary format.

## What it would involve
- Port the geobuf parser from sprint-antoine
- Integrate with the location sensor type
- Add tests for geobuf import/export
