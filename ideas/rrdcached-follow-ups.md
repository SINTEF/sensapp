# RRDCached Follow-Ups

These are optional follow-ups for RRDCached. They are not part of the active roadmap unless the backend is promoted beyond its current experimental role.

## Ideas

- Support additional RRD consolidation functions where query semantics justify it
- Revisit cleanup and isolation semantics if RRDCached is ever expected to participate in broader shared backend tests
- Consider a separate metadata sidecar if richer sensor metadata becomes important for RRDCached use cases
